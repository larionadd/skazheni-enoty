# Квестопис — Редактор текстів сюжетних квестів

Окремий легкий вебдодаток для створення, вичитки та порівняння текстів сюжетних квестів. Працює автономно в браузері як на настільних комп'ютерах, так і на смартфонах без встановлення додаткового серверного ПЗ.

---

## Основні можливості

1. **Двоколонковий робочий процес (Оригінал vs Моя редакція):**
   - Вставлений первинний текст автоматично дублюється в поле редакції.
   - Початковий оригінал захищено: при спробі замінити його за наявності зміненої редакції з'являється попередження з варіантами дій (створити нову сцену, перезаписати, або зберегти поточні правки).

2. **Підсвітка відмінностей на рівні слів:**
   - Алгоритм диференціації (Myers diff) з токенізацією, оптимізованою під українську мову (підтримуються апострофи `’`, `'`, дефіси в словах на кшталт `будь-хто`, тире та лапки `«»`).
   - Зміна одного слова в реченні чи довгому абзаці підсвічує **лише це слово**, а не весь абзац.

3. **Режим «Порівняння» з доступністю:**
   - **Об'єднаний вигляд (Inline):** текст читається суцільно з позначенням доданого та вилученого.
   - **Паралельний вигляд (Side-by-side):** дві колонки (оригінал та редакція).
   - **Доступність не лише кольором:**
     - `[+]` Додані слова: зелене тло + суцільна нижня лінія + семантичний тег `<ins>` + бейдж `[+]`.
     - `[-]` Вилучені слова: червоне тло + перекреслення + семантичний тег `<del>` + бейдж `[-]`.
     - Повні підписи ARIA для читачів екрана (`aria-label`).

4. **Адаптивний інтерфейс (ПК та Смартфони):**
   - **На комп'ютері:** дві колонки поруч із перетягуваним розділювачем (Splitter) та швидкими кнопками пропорцій (50/50, 40/60, 60/40).
   - **На телефоні:** вкладки «Оригінал», «Моя редакція», «Порівняння» без горизонтального прокручування. Великі сенсорні кнопки (44px+).

5. **Автозбереження, скасування та історія версій:**
   - Миттєве локальне збереження в `LocalStorage`.
   - Кнопки «Скасувати» / «Повторити» та гарячі клавіші `Ctrl+Z` / `Ctrl+Y`.
   - Ручні та автоматичні знімки версій із можливістю відкату до попереднього стану.

6. **Багатосценність (Окремі документи / сцени):**
   - Створення, перейменування, дублювання та вилучення окремих розділів і сцен квесту з індивідуальною статистикою.

7. **Експорт та резервне копіювання:**
   - Копіювання готового тексту в буфер одним кліком.
   - Завантаження готової редакції як `.txt` або `.md`.
   - Повний експорт та імпорт усіх сцен з історією у файл `.json`.

## Архітектура синхронізації

Застосунок розроблено за принципом **Offline-First**. Наразі дані зберігаються локально в браузері.
У файлі `app.js` реалізовано глобальний інтерфейс `window.QuestSyncAdapter`:
```javascript
window.QuestSyncAdapter = {
  currentProvider: 'offline-local',
  getStatus() { ... },
  registerRemoteProvider(provider) { ... }
};
```
Це дозволяє у наступних версіях без зміни інтерфейсу підключити:
- Приватний WebRTC peer-to-peer обмін між телефоном і ПК за QR-кодом.
- Наскрізне шифрування (E2EE) з власним сервером або WebDAV/CouchDB.

## Як запустити

Просто відкрийте файл `index.html` у будь-якому сучасному браузері на комп'ютері або телефоні (Chrome, Firefox, Safari, Edge):
```bash
# Або через будь-який локальний статичний вебсервер:
# Наприклад:
npx serve quest-editor
# або
python -m http.server 8080 --directory quest-editor
```
